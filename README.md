## 📌 Overview

A fully responsive, interactive, and visually rich **personal portfolio website** built with pure HTML, CSS, and JavaScript — no frameworks required. Features a live **Three.js 3D particle background**, smooth scroll animations, a 3D tilt profile card, and a full showcase of skills, services, and projects including a **live AI Data Analyst Agent**.

---

## ✨ Features

- 🎯 **3D Particle Background** — Live Three.js animation with mouse-reactive camera movement and rotating wireframe tori
- 🃏 **3D Tilt Profile Card** — Interactive hero card with perspective tilt on mouse movement
- 🤖 **Featured AI Project Showcase** — Animated browser mockup with live dashboard preview, floating code particles, and glowing effects
- 📊 **Animated Skill Bars** — Progress bars that animate on scroll into view
- 🔍 **Scroll Reveal Animations** — All sections fade and slide in as you scroll
- 📱 **Fully Responsive** — Optimised for desktop, tablet, and mobile
- 🌙 **Dark Professional Theme** — Deep dark background with blue and teal accents
- 🧭 **Active Nav Highlighting** — Navbar auto-highlights the current section as you scroll
- 📬 **Contact Form** — Functional form with validation feedback
- ⬆️ **Scroll to Top Button** — Appears after scrolling down

## 🌍 Deployment

This portfolio is a **single HTML file** — deploy it anywhere in seconds:

**Option 1 — Netlify Drop (Fastest)**
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop `index.html`
3. Get a live link instantly — no account needed

**Option 2 — GitHub Pages**
1. Push the file to a GitHub repository as `index.html`
2. Go to **Settings → Pages → Source → main branch**
3. Your site will be live at `https://yourusername.github.io/repo-name`

**Option 3 — Firebase Hosting**
```bash
npm install -g firebase-tools
firebase login
firebase init hosting
# Place index.html in the public folder
firebase deploy
```
